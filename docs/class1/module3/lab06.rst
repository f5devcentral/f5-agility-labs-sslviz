User Authentication
================================================================================

.. image:: ./images/l3outbound-3-auth-0.png
   :align: center

|

SSL Orchestrator can require a user to authenticate before traffic will be proxied.

.. note::
   This leverages the BIG-IP Access Policy Manager (APM) software module functionality, so requires an APM license on the SSL Orchestrator system. To learn more about APM, click `here <https://www.f5.com/products/big-ip-services/access-policy-manager>`_.

|

.. image:: ./images/l3outbound-3-auth-1.png
   :align: center

|

No user authentication will be enabled at this time. This topic is covered in one of the advanced-level SSL Orchestrator courses.
